## 審查、限制與停止

- SQL 使用固定查詢＋參數值，僅初始化執行固定 schema；沒有串接使用者 SQL。畫面理由、名稱及錯誤使用 textContent／Option，沒有 innerHTML。
- 每請求 DB 連線在同一工作執行緒開關；唯一 POST commit 在服務；API 登記與未知 API 處理在靜態 Mount 之前。import 不開 DB；明確 db_path／時鐘注入優先環境。
- 未做完整 HTTP 錯誤矩陣、多重錯誤全組合、所有空白碼位、極端日期、損毀／斷電恢復、所有並行操作或效能測量；不宣稱全規格分支／安全稽核均通過。
- 未加入核准、額度、登入或 LLM。未自動 commit／push，停在本票等待使用者驗收。
